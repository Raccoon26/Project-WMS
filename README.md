# Project-WMS

Warehouse and marketplace operations platform: approximately 10 current SKUs, **at least 50 supported at initial release**, with no arbitrary 50-SKU hard cap.

## Planned (not yet implemented)
- React/TypeScript PWA + Fastify/Node.js + PostgreSQL on Raspberry Pi 5
- External warehouse shipment instruction by email and Excel/PDF forms
- Amazon FBA and Rakuten RMS/RSL integrations; future own warehouse + carrier connections
- Telegram notifications/approval; encrypted Google Drive backups
- Optional FUTURE Dot analytics assistant (not subscribed/connected yet); all operational workflows must run independently of Dot and paid AI APIs

**Status:** DEV-00 GitHub bootstrap only. Inventory, API, deployment and auto-merge have NOT yet been released.

See [GitHub workflow](docs/GITHUB_WORKFLOW.md), [safety invariants](docs/SAFETY_GATES.md), and [Codex rules](AGENTS.md).
